# 💊 Wadjet Pharmacy

Smart Pharmacy is a responsive pharmacy web application that allows customers to browse medicines, search for products, add items to their shopping cart, and place orders through a clean and user-friendly interface. The system also provides an admin dashboard to manage products, categories, suppliers, customers, and orders.

---

## 🚀 Features

### Customer

- Browse medicines
- Search products instantly
- Filter by category
- View product details
- request for out-of stock products
- Add products to cart
- Checkout system
- User authentication
- Responsive design

### Admin

- Dashboard with statistics
- Product management (CRUD)
- Category management
- Supplier management
- Customer management
- Order management
- availability requests management

- CSS3

## 🎯 Project Goal
